# 野有镜 · WILDFRAME

一个纯网页 3D 拟人动物摄影游戏，使用 Three.js 和 Vite。单人无需后端，多人使用 WebRTC 与可选自建信令。

## 本地运行

```sh
npm ci
npm run dev
```

## 操作

- 鼠标拖动：环绕；右键拖动：平移；滚轮：前后移动。
- W / A / S / D：移动相机；↑ / ↓：升降；空格：拍照。
- 焦距滑块：24–100 mm。
- 触屏：单指环绕，双指缩放与平移。
- 支持兔子、乌龟切换；构图网格；重置相机；JPEG 下载；本地影集（最近 24 张）。

## 挑战与评分

三项游戏内原创挑战：温柔的对视、三分之一的诗、小小的，大世界。参考作品直接由当前模特的 3D 场景渲染。照片按主体落点（43%）、画面占比（40%）、机位高度（17%）与参考构图比较，得分可复现。主体被裁切最高 50 分，离开画面为 0 分；85 / 70 / 55 分分别为金奖 / 银奖 / 入围。

这些是游戏内构图挑战，并非真实摄影奖项；目前不包含 AI 审美识别、真实奖项数据库或云端账号同步。场景和角色均为程序化原创几何模型。

## 多人摄影派对（2–8 人）

1. 点击「联机摄影派对」，填写昵称，选择「我来创建房间并当模特」。
2. 复制邀请链接发给朋友，或让朋友输入 8 位房间码加入。默认使用 PeerJS 公共信令服务，无需账号；服务是否可达取决于网络。
3. 房主选择本轮模特、构图主题和 30 / 60 / 90 秒时长，开始比赛。房主可以将模特角色交给其他玩家，自己成为摄影师。
4. 模特使用 WASD 走位、Q / E 转身，或点击触屏方向按钮；姿势菜单支持自然站姿、侧头沉思、张臂欢呼。模特动作同步给所有摄影师。
5. 摄影师各自移动相机并拍照。参赛画幅统一为 3:2，房主按固定主题和拍摄时的模特状态重新计算构图分数，不采纳客户端自报分数；每人保留最高分。
6. 时间到后公开作品墙及排名，同分并列。作品可下载。房主可以换模特开始下一轮。

「直播展示」隐藏普通界面，突出房间码、倒计时、场景与作品墙，可供 OBS 窗口捕获。它不是音视频推流服务，不会读取真实摄像头或麦克风。游戏内照片和昵称会发送给房间内玩家。

房主的浏览器就是本局主机。房主关闭页面或断线后房间结束，其他玩家返回单人模式；目前不支持主机迁移、断线恢复旧身份、观众投票或强防作弊。房主是受信任的裁判；浏览器无法验证参赛 JPEG 与相机数据是否确实对应，因此适合朋友聚会，不用于有真实奖品的正式竞赛。

### 用户自建信令服务

前端保持纯静态，可继续部署到 GitHub Pages。联机使用 WebRTC 数据通道；信令服务用于建立连接，不保存影集。可以使用公共服务，也可以自己运行：

```sh
npm ci
npm run signaling
```

默认监听 9000 端口，路径 `/wildframe`，可通过 `PORT` 环境变量调整端口。反向代理时设置 `PROXIED=true`。

- 本机测试：各浏览器页面的「自建主机 / 网络设置」填写 `http://127.0.0.1:9000/wildframe`，ICE 配置填 `[]` 即可测试同机点对点连接。
- 公网开服：将该服务放到你自己的服务器或反向代理后，提供 `https://signal.example.com/wildframe`。代理须转发 WebSocket Upgrade；所有玩家使用同一信令地址。HTTPS 游戏页面不能连接 HTTP 信令。
- 邀请链接包含房间码和自建信令地址，不包含 TURN 凭据。点击链接不会自动连接；玩家确认加入后才建立连接。TURN 配置不持久化，刷新页面后需重新填写。
- 部分 NAT / 企业网络无法直连，需要自行部署或购买 TURN，在每位玩家的 ICE 配置中填写 JSON 数组，例如：

```json
[{"urls":"stun:stun.example.com:3478"},{"urls":"turn:turn.example.com:3478","username":"temporary-user","credential":"temporary-password"}]
```

以上域名是配置示例，不是内置可用服务。不要把长期 TURN 密钥写入前端源码。自建 PeerServer 不会自动提供 TURN。参考 [PeerJS 客户端 FAQ](https://peerjs.com/client/faq) 与 [自建 PeerServer 文档](https://peerjs.com/server/getting-started)。

### 验证

`npm test` 检查角色权限、房间人数、主机评分、截止时间、最高分保留、静止模特状态、过期照片以及无效数据。浏览器联机测试使用本机自建信令和三个独立页面，验证两位摄影师交片、倒计时、赛后排名、角色轮换和模特离开；公网跨 NAT 的连接质量需要在目标网络与 TURN 配置下另行验证。

## GitHub Pages

已提供 `.github/workflows/pages.yml`。在 GitHub 仓库 Settings → Pages → Source 选择 **GitHub Actions**，推送到 `main` 或 `master` 后自动构建发布。Vite 使用相对资源路径，可部署到仓库子路径。

```sh
npm run build
```

构建输出为 `dist/`。预期发布地址： https://tyrantqiao.github.io/takePhotoGame/ 。

影集存储于当前浏览器 localStorage；清除站点数据会删除影集，请下载重要照片。界面字体使用 Google Fonts，加载失败时回退到系统字体。

## 角色与地标摄影（本次美术更新）

- 兔子「棉棉」：直立长腿、蓝灰西装外套、衬衫领带、长耳和口鼻细节。
- 乌龟「慢慢」：直立双腿、暖棕夹克、圆框眼镜和背部龟甲。
- 肩部、手臂、腿部和头部具有独立姿态节点；单人也能选择自然站姿、侧头沉思、张臂欢呼。构图参考会暂时恢复中立姿态，生成后完整还原关节，避免影响拍照与主机评分。
- 京都「千本鸟居」：连续朱红门廊、黑色横梁、石灯笼、木构茶屋与林木。
- 巴黎「铁塔广场」：四腿格构铁塔、底部拱线、广场铺石、行道树、路灯和喷泉。
- 圣托里尼「蓝顶海岸」：蓝色半球穹顶、白墙小楼、海面、露台与花盆。

以上均为程序化原创模型。角色借鉴拟人动物都市叙事与服装化设计方向；不是《动物狂想曲》的官方角色或素材。地图是以真实地标特征为灵感的摄影布景，使用游戏尺度和重新编排的街区，不是测绘级、逐建筑或一比一复刻。

单人点击地图卡片自由切换。多人由房主在开拍前选地图，所有参与者同步；开拍后锁定地图。新创建房间沿用房主当前地图。协议版本提升至 v3，旧版本房间不互通，参加同一局前请刷新到相同版本。

设计参考：[BEASTARS 官方介绍](https://about.netflix.com/en/news/beastars-final-season-part-1-arrives-on-december-5)、[伏见稻荷千本鸟居](https://inari.jp/en/map/spot_07/)、[埃菲尔铁塔结构与历史](https://www.toureiffel.paris/en/the-monument/history)、[希腊旅游局 Oia 建筑影像](https://archivecollections.visitgreece.gr/entities/photo/2ca04619-d023-4ef5-b08c-a11f8f1f0724)。没有下载或嵌入来源网站的图片。


## 协作镜头与 1 / 4 / 9 张组照

- 相机支持向上仰拍，保留地面高度保护；可拖动俯仰、调节 0.15–10 米机位高度，或点击「低机位仰拍」切到 0.35 米。
- 房主选择单张、四宫格或九宫格。模特负责按镜头清单走到地面圆环、转身并摆姿；模特能切换当前镜头，摄影师共享同一任务进度。
- 镜头对应自然站立、回眸、欢呼、招手、指向和护胸六种姿态。UI 显示目标坐标、当前坐标、距离和朝向误差，任务标记不会出现在最终照片中。
- 每位摄影师的每个镜头单独保留最高分；组照总分为所有格子的平均值，未拍格子计 0 分。85 分视为该格达标，全部达标才显示「完美组照」。
- 协作评分权重：主体落点 35%、景别 20%、相机高度与俯仰 15%、模特站位 15%、摆姿 10%、朝向 5%。模特未满足站位 / 姿态 / 朝向条件时最高 54 分；裁切最高 50 分，出框 0 分。
- 房主核验照片所属任务和历史模特状态，不能用同一任务照片伪填其他格子。回合到时或房主提前收工后公开组照；可预览并下载带昵称、分数和缺格标记的整套 JPEG。
- 建议 1 / 4 / 9 张分别用 60 / 180 / 300 秒；主机仍须保持页面在线。
- 参考库包含 5 张实图、4 条圈内梗出处索引。实际收录、原作者和源页面见 public/references/SOURCES.md。用户提供的获奖故事未作真实赛事背书；这里使用中性的「逆光回眸」命名。
- 评分比较人工定义的几何构图与配合动作，不是图片审美 AI、人物身份或像素相似度识别。真实光照方向、表情情绪和背景遮挡目前不进入评分。

协议为 v3，旧版本房间需刷新后重新建立。13 项自动测试覆盖向上仰拍、地面保护、任务合作、九格缺图计零、重复照片防填格、历史任务归属及原有房间权限。

## 沉浸式游戏界面

打开游戏先进入以实时 3D 场景为背景的主菜单，可开始自由摄影、创建 / 加入多人派对、查看图鉴和指南。进入游戏后使用全屏取景器与底部 HUD；地图、演员、影集和房间使用浮层面板，镜头与任务清单使用可收起的游戏内面板。支持系统全屏，窄屏也保持场景占满画面。

- 点击右上暂停按钮或按 Esc 暂停 / 继续；面板打开时 Esc 先关闭面板。
- 单人暂停会冻结相机和输入；切换到其他标签页时自动暂停。返回主菜单保留浏览器影集。
- 多人摄影师的暂停菜单仅冻结自己的操作，比赛继续计时。房主在拍摄中暂停会同步全场、保存剩余时间，继续后恢复倒计时。其他玩家不能解除房主暂停。
- 返回主菜单会退出当前房间；房主退出会结束房间。模特离开或房主收工会清除暂停状态，避免其他玩家停留在等待界面。

当前联机协议为 v4，参与同一房间前请刷新到相同版本后重新建房。17 项自动测试覆盖游戏流程、暂停权限、剩余时间恢复、暂停期间提交拦截、模特退出及原有摄影 / 联机规则。
